# Halloween Event Organiser

## Description
A web based system for organising and scheduling events for halloween. Make an account and host or sign up for events. All information is stored in a database so will be there for everyone.

## Features
You can:
- Make an account
- Login
- Create events
- Sign up for events
- View who is going to events
- Edit event information
